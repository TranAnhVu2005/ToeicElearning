# TOEIC Learning — Project Context
> Tóm tắt nhanh cho agent; ưu tiên gọn và tối đa khoảng 130 dòng khi cần ghi nhận mốc triển khai. Chi tiết sản phẩm nằm trong `docs/01_OVERVIEW.md`–`docs/06_SECURITY_SPEC.md`. Mã nguồn/schema là nguồn xác nhận trạng thái thực tế.

## Mục tiêu
- Website luyện thi TOEIC thương mại: Admin (đề/user/payment/dashboard/duyệt teacher), Teacher (lớp/tài liệu/đề/assignment), Student (thi/luyện/review/lớp/notification), đề VIP/VNPAY.
- Chủ dự án đã yêu cầu tiếp tục triển khai và sửa lỗi theo các yêu cầu/đặc tả hiện hành; giữ kiến trúc và chỉ coi các mục đã chốt là phạm vi bắt buộc. Tính năng đề xuất cần được phân biệt rõ.
## Stack và entry points
- Backend: Java 17, Maven WAR, Spring Boot 4.1.0, Spring Data JPA, Spring Security, MySQL; port 8080. Hibernate SQL logging mặc định tắt, chỉ bật tường minh qua `JPA_SHOW_SQL=true` khi debug cục bộ.
- Frontend: React 19, Vite, React Router, Tailwind CSS, Axios; dev mặc định 5173; gọi `http://localhost:8080/api`. LocatorJS emits extension-compatible `data-locatorjs-id` + registry; Vite config escapes the registry key on Windows. Restart Vite after config edits.
- Mọi page route được tải bằng `React.lazy` trong `App.jsx`, có Suspense loading; build hiện tách chunk và main JS giảm từ ~789 KB xuống ~314 KB (chunk route lớn nhất hiện ~198 KB).
- Backend root package: `backend/src/main/java/com/ctu_cit_nienLuanNganh/toeicLearning/`.
- Frontend routes/layout: `frontend/src/App.jsx`; API client/auth: `frontend/src/api/apiClient.js`, `frontend/src/context/AuthContext.jsx`, `frontend/src/services/`.
- Thi: `frontend/src/pages/ExamTakePage.jsx`; soạn đề: `frontend/src/pages/admin/TestManagementPage.jsx` (file lớn, autosave/local recovery/server draft save).
- Kiến trúc cần giữ: một backend Spring Boot modular monolith dùng REST/JWT và một React/Vite SPA. Tính năng mới mở rộng cấu trúc này; không tự chuyển framework, tách microservice/BFF hay tái cấu trúc diện rộng.
## Bản đồ backend
- Modules hiện có: `auth`, `exam`, `user`, `admin`, `media`, `classroom`, `notification`; lớp học có flow tạo lớp/roster, assignment/feedback, tài liệu PDF private và đề riêng gắn classroom. Admin metrics/presence bổ sung trong module `admin`/`user`.
- Entities chính: `Role`, `User`, `Test`, `Part`, `ContextQuestion`, `Question`, `TestResult`, `UserAnswer`; thêm lớp học/tài liệu/bài tập, `PaymentTransaction`, `Notification`.
- Quan hệ đề: `Test -> ContextQuestion -> Question`; `orderIndex` là số câu bắt đầu của context, `questionNumber` là số global.
- Auth routes: POST `/api/auth/register`, `/login`, `/google`. Google ID token được xác minh chữ ký RS256 bằng JWK cache từ Google, kiểm tra issuer/audience/time/email_verified; định danh `sub` lưu unique trong `user.google_sub`; không auto-link local account theo email.
- Exam routes: GET `/api/exam/list`, `/{testID}`, `/{testID}/parts/{partID}`, authenticated `/{testID}/dictation`; API Part xác nhận đề có context thuộc Part được yêu cầu, sai đề trả `PART_NOT_FOUND`; submit lọc Part an toàn cả với dữ liệu context legacy thiếu quan hệ Part; admin list/detail ở `/api/exam/admin/**`; CRUD/publish/draft chỉ ADMIN. Đề có lượt làm/giao dịch/assignment chỉ cho phép cập nhật metadata an toàn qua `PATCH /api/exam/update/{id}/metadata`; cập nhật nội dung bị chặn với `TEST_HAS_HISTORY`, xóa đề hệ thống lưu tham chiếu bằng cách archive về DRAFT.
- User routes: GET `/api/user/me`, PATCH `/api/user/updateprofile`, POST `/api/user/changepassword`, POST `/api/user/setpassword`. Google-only account có thể đặt mật khẩu local sau khi xác minh ID token Google mới tối đa 5 phút và `sub` khớp; hash BCrypt, tăng `authVersion`, yêu cầu đăng nhập lại. Profile DTO chỉ thêm cờ `hasLocalPassword`/`canSetLocalPassword`, không lộ hash hoặc Google `sub`.
- Admin routes: GET `/api/admin/users`, PATCH `/api/admin/changestatus`; GET `/api/admin/payments` tra cứu giao dịch theo trạng thái/ngày/người trả/email/mã tham chiếu, chỉ ADMIN. Media upload ADMIN/TEACHER: decode JPEG/PNG ≤5 MiB, signature/structure MP3/WAV/M4A ≤20 MiB, giới hạn chiều ảnh 8000 và 20MP, folder trong namespace app; avatar dùng cùng validation. Profile multipart bỏ JSON content-type để browser thêm boundary. Cover upload kiểm tra Cloudinary cloud name/API key/API secret đã được cấu hình; thiếu biến trả `MEDIA_STORAGE_NOT_CONFIGURED` (503). Lỗi provider không log response body hay secret; chỉ ghi loại lỗi/phân loại an toàn. Rate limit media 30/IP + 20/user và PDF lớp 30/IP + 10/teacher mỗi 15 phút, bucket hash MySQL. Upload chọn `resource_type` theo folder. Xóa bằng URL client đã bị gỡ; internal cleanup kiểm tra HTTPS host/account và namespace `Resource/toeic-learning/`. Avatar thiếu/lỗi hiển thị icon local; không dùng URL fallback SVG không tồn tại.
- Thi/review đã có backend: POST `/api/exam/submit` chấm server-side và lưu `TestResult`/`UserAnswer`; GET `/history` và `/results/{id}` chỉ trả kết quả của user hiện tại. UI có trang riêng xem lại kết quả tại `/results/{id}` với câu trả lời, đáp án, lời giải, audio/transcript; lịch sử đề dùng API thay vì dữ liệu mẫu.
- Luồng thi không còn tạo câu hỏi/đáp án mẫu khi API thiếu dữ liệu hoặc dùng ID giả: báo nội dung đề thiếu để quản trị viên sửa. Frontend build thành công; chưa chạy lint/test.

## Dữ liệu đề và quy tắc cốt lõi
- Part 1: 6 câu, 1–6; mỗi câu ảnh + audio, lựa chọn chỉ A/B/C/D.
- Part 2: 25 câu, 7–31; mỗi câu audio, UI chỉ A/B/C.

## Security và cấu hình
- JWT Bearer gồm subject user ID + `authVersion`; filter nạp user/role từ DB, so version và từ chối account locked. Có `frontend/.env.example` đã được allowlist trong `.gitignore`; production cần đặt HTTPS API URL và exact frontend origin trong `APP_CORS_ALLOWED_ORIGINS`.
